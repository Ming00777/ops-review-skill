# 反运营黑话指南

运营复盘最容易被一眼看穿的地方：话术很满，数据很空。

---

## 硬性规则

### 规则一：每个结论后面必须跟数字

**不合格：**
> 本周用户活跃度有明显提升，社群氛围持续向好。

**合格：**
> 社群日活 342 人，环比 +18%（上周 290），主要来自周三那次秒杀活动带来的 52 人。

写不出数字的结论，**直接删掉**，不要试图用形容词凑。

### 规则二：禁止黑话

见到这些词直接删，一个都不留：

```
赋能  抓手  闭环  打法  心智  颗粒度  拉通  对齐  沉淀
组合拳  阵地  链路  室内 brewing  精细化运营  提质增效
打通  链路  卡位  曝光 Harbor  全链路  沉淀方法论
```

判断标准很简单：**把这个词删掉，句子意思变了吗？** 没变，说明它是空的。

### 规则三：不许只报喜

数据往下走的指标必须写，不能因为不好看就不提。
**只写增长的复盘 = 没复盘。** 领导最想看的恰恰是问题部分。

### 规则四：归因要具体到能追责

**不合格：**
> 转化率下降主要受市场环境影响。

**合格：**
> 渠道 B 落地页 3/12 改版后，该渠道转化率从 3.2% 跌到 1.4%，
> 拖累整体支付转化 0.6pp。建议回滚，预计挽回 0.4~0.6pp。

归因到"市场环境"等于没归因。要具体到**哪个渠道、哪次改动、影响了多少**。

### 规则五：下一步动作必须有负责人和时间

**不合格：**
> 建议优化落地页，提升转化。

**合格：**
> 回滚渠道 B 落地页 — 张伟，周三前完成，预计 9/22 周报可见回升

没有负责人和时间的动作 = 不会发生。

## 好复盘的结构

```
## 核心结论（3 条以内，每条带数字）
一句话说清这周做得怎么样，最好的和最差的各一条。

## 异常说明（围绕脚本标出的异常）
- 什么指标、跌/涨了多少、历史上处于什么位置
- 归因：具体到渠道/动作/时间点
- 影响面：拖累/拉动整体多少

## 做得对的部分（可复用）
不只是问题，有效的动作要说清楚，因为要复制。

## 下周动作
1. [动作] — [负责人]，[时间]，[预期效果]
2. ...

## 需要支持/风险
需要别的团队配合的、可能有风险的，提前说。
```

---

## 自检清单

交出去之前对着过一遍：

- [ ] 每个结论后面都有数字吗？
- [ ] 有黑话吗？（删了意思不变的词）
- [ ] 下跌的指标写了吗？还是只挑好看的写？
- [ ] 归因具体到渠道/动作/时间了吗？
- [ ] 下一步有负责人和截止时间吗？
- [ ] 拿给一个不了解这件事的人看，他能看懂问题在哪吗？

**最后一条最重要。** 复盘的读者是领导和协作方，他们没有你的上下文。
