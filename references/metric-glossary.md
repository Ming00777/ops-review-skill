# 运营指标口径词典

> **v0.1 通用版。** 口径这种东西，同一家公司不同团队都可能不一样。
> 用之前先拿自己的业务校准，把改过的地方写回来——**词典一旦校准准了，它就是这个 Skill 最值钱的部分**，因为外面的人抄不走。

## 用之前必须先做的事

**问用户三个问题，别自己假定：**

1. 这张表的每个指标，你们内部怎么定义的？
2. 分母是什么？（90% 的口径分歧出在分母）
3. 有没有目标值？目标是谁定的、什么时候定的？

问不清楚就写复盘，等于编数据。

## 交易类

### GMV（成交额）

最容易被含糊对待的指标。必须确认：

- **含不含退款？** 含退款的是 GMV，不含的是净成交额（NMV）
- **含不含未支付订单？** 有些公司"拍下即计入"，有些"支付才算"
- **含不含运费？** 含税与否？

常见陷阱：周报 GMV 涨了，实际是因为退款率上升滞后没体现。**看 GMV 必看退款率。**

### 客单价

```
客单价 = GMV / 下单用户数   ← 通常指这个
件单价 = GMV / 销售件数     ← 不一样，别混
```

上涨不一定是好事——可能是低价商品断货，只剩贵的在卖。

### 动销率

```
动销率 = 有销量的 SKU 数 / 在售 SKU 数
```
或按商家算：`动销商家数 / 总商家数`（B 端业务常用这个）

**这两个不能混用。** 做商家运营看后者，做品类运营看前者。

## 转化类

### 转化率（最容易产生分歧）

三个完全不同的东西，必须确认是哪一个：

| 名称 | 公式 | 用在哪 |
|---|---|---|
| 点击率 CTR | 点击 UV / 曝光 UV | 看素材和封面 |
| 下单转化率 | 下单 UV / 访问 UV | 看详情页和商品力 |
| **支付转化率** | 支付 UV / 访问 UV | **看整个链路，最常被当作"转化率"** |

**分母是 UV 还是 PV？** UV 去重，PV 不去重。同一个人刷三次页面，PV 转化率会被稀释。

### 漏斗

```
曝光 → 点击 → 加购/进店 → 下单 → 支付
```

看漏斗不要只看整体转化率，要看**哪一环掉了**。整体从 5% 掉到 4%，可能是点击环节掉了（素材问题），也可能是支付环节掉了（价格或库存问题）——**对策完全不同。**

## 用户类

### 新客 / 老客

- 新客定义：首次下单？首次注册？还是窗口期内没购买过的？
- **窗口期多久？** 常见 30 天 / 90 天 / 自然年内

窗口期不同，新客数能差出一倍。

### 复购率

```
复购率 = 周期内购买 ≥2 次的用户 / 周期内总购买用户
```
**周期必须先定**：30 天复购、90 天复购、年度复购，数值差很多。

### 留存（偏产品侧，运营也会看）

```
次日留存 / 7 日留存 / 30 日留存
```
分母是**新增用户**，不是活跃用户。

### CAC（获客成本）

```
CAC = 投放花费 / 新增用户数
```
注意：是**新增付费用户**还是**新增注册用户**？后者会让 CAC 看起来很好看，但没意义。

## 效率类

### ROI / ROAS

```
ROAS = 收入 / 花费      ← 只看收入
ROI  = (收入 - 花费) / 花费  ← 看利润
```

**这两个经常被混叫。** 报 ROI 报成 ROAS 是常见的美化手法。

### 达成率

```
达成率 = 实际 / 目标
```
超过 100% 不一定是好事——可能目标定低了。低于 100% 也不一定是坏事——可能目标定高了。
**写复盘时要说明目标本身的合理性**，而不是只报数字。

## 口径自查表

写复盘前，对着这份清单确认一遍：

- [ ] 每个指标的分母确认过了
- [ ] 时间口径一致（都是自然周？还是最近 7 天？）
- [ ] 有没有把不同口径的数据放在一起比
- [ ] 除退款、含运费这些细节确认过了
- [ ] 目标值是哪版预算里的
